About Position:

We are looking for an experienced Senior Java Full Stack Developer to design, develop, and maintain scalable enterprise applications. The ideal candidate will have strong expertise in Java backend development, modern frontend technologies, microservices architecture, and event-driven systems. This role requires hands-on experience in building high-performance applications using Java, Spring Boot, React.js, Kafka, and MongoDB while working closely with cross-functional teams in an Agile environment.

Role: Senior Java Full Stack Developer
Location: Bengaluru, Hyderabad
Experience: 5 to 9 Years
Job Type: Full-Time Employment

What You'll Do:

Design, develop, and maintain scalable backend services using Java and Spring Boot.
Build and enhance microservices-based applications following modern architecture principles.
Develop and maintain responsive, reusable, and high-performance user interfaces using React.js.
Implement event-driven solutions and asynchronous messaging using Apache Kafka.
Design and develop RESTful APIs and backend integrations.
Work with MongoDB and other databases for efficient data storage and retrieval.
Participate in application architecture discussions and contribute to technical design decisions.
Collaborate with product managers, architects, QA teams, and business stakeholders to deliver high-quality solutions.
Perform code reviews and ensure adherence to coding standards, security practices, and development best practices.
Troubleshoot, debug, and resolve application issues across the technology stack.
Optimize application performance, scalability, and reliability.
Participate in Agile ceremonies including sprint planning, daily stand-ups, retrospectives, and backlog refinement sessions.
Contribute to CI/CD processes and support application deployment activities.
Create and maintain technical documentation, design specifications, and implementation guidelines.

Expertise You'll Bring:

5 to 9 years of hands-on experience in Java Full Stack Development.
Strong expertise in Core Java, Java 8+, and object-oriented programming principles.
Extensive experience in Spring Boot and microservices architecture.
Hands-on experience with React.js and modern frontend development practices.
Strong understanding of REST APIs and web services development.
Experience implementing event-driven architectures using Kafka.
Hands-on experience working with MongoDB and NoSQL databases.
Good understanding of distributed systems and microservices-based application design.
Experience working in Agile/Scrum delivery environments.
Familiarity with version control systems such as Git.
Experience with application debugging, troubleshooting, and performance optimization.
Understanding of security, scalability, and reliability best practices for enterprise applications.
Strong analytical, problem-solving, and debugging skills.
Excellent communication and collaboration abilities.
Ability to work effectively in cross-functional and globally distributed teams.
